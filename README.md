# Obfuscator v1.0

Универсальный обфускатор кода с поддержкой Python, Java, Kotlin, JavaScript, TypeScript, Lua, C#, C/C++, PHP, Ruby.

## Возможности

- 4 уровня обфускации (Лёгкий, Средний, Сложный, Максимальный)
- Поддержка 11 языков
- Два режима: Универсальный и По типу
- Шифрование строк, переименование переменных, мёртвый код
- Тёмная тема, анимации, RU/EN
- Портативный EXE
